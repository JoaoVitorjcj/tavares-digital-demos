# tavares-digital-demos

Site institucional da **Tavares Digital** (Manaus, AM) e modelos de demonstração, publicado com GitHub Pages.
Repositório público: não coloque aqui dados reais de clientes, segredos ou propostas com nome de prospect.

## Versões
- `main`: versão publicada (v0.1).
- `feat/portfolio-salao`: v0.2 intermediária (só o salão como quarta aba do portfólio); fica como histórico.
- `versao/v0.3-logo-e-salao`: logo nova, salão de beleza como terceiro exemplo e imagem de compartilhamento. Detalhes em `docs/versoes/v0.3-logo-e-salao.md`.
- Regra de trabalho: cada mudança aprovada entra como versão nova (branch e documento em `docs/versoes/`), sem substituir a anterior.

## Estrutura
- `index.html`, `td-style.css`, `td-app.js`: página institucional (HTML, CSS e JS sem build).
- `ilustrado/`, `original/`, `claude/`: modelos AutoPrime (oficina fictícia). `salao/`: modelo Casa Aurora (salão fictício).
- `assets/`: capturas do portfólio, favicon e imagem de compartilhamento; `assets/logo/`: logotipos; `assets/anteriores/`: arquivos de versões passadas.
